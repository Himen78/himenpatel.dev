# himenpatel.dev

Personal portfolio of **Himen Patel**, Senior SDET · Automation Architect · Agentic AI.

A single, dependency-free `index.html` (HTML + CSS + vanilla JS). Fonts and icons load from Google Fonts and Font Awesome CDNs.

## Features
- Light/dark theme that follows the system setting, remembers your choice, and doesn't flash light on reload
- Responsive layout with a mobile menu
- Experience timeline with collapsible details
- Nav highlight for the current section, copy-email button
- SEO: meta description, Open Graph/Twitter cards, JSON-LD `Person` schema
- Accessibility: skip link, focus styles, ARIA labels, `prefers-reduced-motion` support

## Run locally
Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy
Works as-is on GitHub Pages, Netlify or Vercel (static hosting, no build step).
